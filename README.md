# My Website

This is a web project developed using various modern technologies. It includes a full-stack solution with **Express** as the backend and **React** with **Vite** for the frontend. The project uses several other powerful tools and libraries for a smooth user experience, internationalization, and more.

## Technologies Used

### Frontend
- **React**: A JavaScript library for building user interfaces.
- **Vite**: A next-generation, fast build tool for modern web projects.
- **Bootstrap**: A CSS framework for creating responsive and mobile-first websites.
- **SweetAlert2**: A library for beautiful, customizable popups.
- **i18next**: Internationalization (i18n) library for React to handle multiple languages.
- **React Router**: A library for routing in React applications.
- **Redux** & **React-Redux**: State management tools for managing the global state of the application.
- **React Icons**: A library for including popular icons in React applications.

### Backend
- **Express**: A minimal and flexible Node.js web application framework for building RESTful APIs.
- **CORS**: Middleware for enabling Cross-Origin Resource Sharing in the backend.
- **Helmet**: A library for securing HTTP headers.
- **Morgan**: A logging library for HTTP requests.
- **Express-rate-limit**: Middleware for limiting repeated requests to public APIs.
- **Express-validator**: Middleware for validating and sanitizing input.
- **Nodemailer**: A module for sending emails from the backend.
- **Resend**: A backend service for handling email sending.

### Development Tools
- **ESLint**: A static code analysis tool for identifying problematic patterns in JavaScript code.
- **SWC**: A fast JavaScript/TypeScript compiler used for building the frontend.
